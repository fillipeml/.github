# Default community health files

This repository is not a project. It holds the files GitHub applies to every other repository
under this account that does not carry its own copy: the
[contributing guide](CONTRIBUTING.md), the [security policy](SECURITY.md), and the
[code of conduct](CODE_OF_CONDUCT.md).

A repository with its own `SECURITY.md` overrides the one here, and several do — a certificate
loader, a webhook verifier and a spreadsheet writer have genuinely different things worth
reporting, and a single generic policy would say nothing useful about any of them.

The profile page itself is [fillipeml/fillipeml](https://github.com/fillipeml/fillipeml).
